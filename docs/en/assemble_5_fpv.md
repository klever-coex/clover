## Frame Assembly

1. Align the 4 arms between the middle and bottom plates, installing the spacer between them.

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/frame/frame_step_1.png" width=700 class="zoom border center"></div>

2. Install M3x12 screws (<a href="#cell7">Cell 7</a>) and M3x40 screws (<a href="#cell6">Cell 6</a>) from the bottom plate side: M3x12 (<a href="#cell7">Cell 7</a>) in the outer arm holes, M3x40 (<a href="#cell6">Cell 6</a>) in the central holes of the bottom plate.

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/frame/frame_step_2.png" width=700 class="zoom border center"></div>

3. Install M3 press nuts (<a href="#cell1">Cell 1</a>) on the middle plate and secure them with screws.

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/frame/frame_step_3.png" width=700 class="zoom border center"></div>

## Motor Installation

1. Install the arm guards as shown in the image.

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/arm_guard_step_4.png" width=700 class="zoom border center"></div>

2. Install the motors into the corresponding holes on the arm using **M3x10 screws** (<a href="#cell13">Cell 13</a>).

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/motor_step_5.png" width=700 class="zoom border center"></div>

> **Caution** Ensure that the motors are secured with M3x10 screws; otherwise, a short circuit between the windings may occur.

## ESC Installation
1. Install the Electronic Speed Controller (ESC) over the M3x40 screws (<a href="#cell6">Cell 6</a>) on the middle plate. The battery power contacts should face backward.

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/esc_step_6.png" width=700 class="zoom border center"></div>

2. Glue the protective covers and thread the motor wires through them. Solder the power wires and the capacitor to the ESC power pads, and solder the motors to the motor pads (see image below).

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/esc_step_7.png" width=700 class="zoom border center"></div>

3. Slide the protective cover onto the power wires, then solder the XT60 power connector. Snap the protective cover onto the power connector.

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/xt60_step_8.png" width=700 class="zoom border center"></div>

## Flight Controller Installation

1. Install the flight controller with the arrow pointing forward, then install M3 nylon nuts (<a href="#cell2">Cell 2</a>) to secure the flight controller.

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/fcu_step_9.png" width=700 class="zoom border center"></div>

2. Install the 6-pin cable between the flight controller and the ESC.

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/fcu_to_esc_step_10.png" width=700 class="zoom border center"></div>

## Video Transmitter Installation

1. Install M3x10 screws (<a href="#cell13">Cell 13</a>) from the bottom side of the plate; from the top side, install the Video Transmitter (VTX) and secure it with M3 nylon nuts (<a href="#cell2">Cell 2</a>).

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/vtx_step_11.png" width=700 class="zoom border center"></div>

2. View with the Video Transmitter (VTX) installed.

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/vtx_step_12.png" width=700 class="zoom border center"></div>

## Quadcopter Assembly

1. Install M3x30 aluminum standoffs (<a href="#cell15">Cell 15</a>) on top, and secure them from the bottom using M3x6 screws (<a href="#cell9">Cell 9</a>).

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/aluminium_30_step_13.png" width=700 class="zoom border center"></div>

2. View with aluminum standoffs installed.

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/aluminium_30_step_14.png" width=700 class="zoom border center"></div>

3. Install the camera mount on the front standoffs as shown in the image below.

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/camera_mount_step_15.png" width=700 class="zoom border center"></div>

4. Install the video camera into the mount using M2x3 screws (<a href="#cell20">Cell 20</a>) and secure it at your preferred camera tilt angle.

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/camera_step_16.png" width=700 class="zoom border center"></div>

5. Connect the camera cable to the camera port on the flight controller, as shown in the image.

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/camera_step_17.png" width=700 class="zoom border center"></div>

6. Install the connector into the antenna mount and tighten it using a propeller wrench (8mm wrench), then connect the antenna connector to the video transmitter and install it on the rear standoffs.

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/backward_mount_step_18.png" width=700 class="zoom border center"></div>

7. Install the ELRS radio receiver and connect it using the cable to the SBUS/CRSF port on the flight controller.

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/elrs_rx_step_19.png" width=700 class="zoom border center"></div>

8. Install the rear protective guards by hooking them onto the standoff near the flight controller and snapping the clip onto the rear standoff.

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/backward_guard_step_20.png" width=700 class="zoom border center"></div>

9. Install the LED modules by sticking them with double-sided tape onto the inner sides of the arms (see image below).

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/led_step_21.png" width=700 class="zoom border center"></div>

10. Connect the LED modules to the hub as shown in the image. Connect the hub to the LED/Buzzer port on the flight controller.

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/led_hub_step_22.png" width=700 class="zoom border center"></div>

11. Route the wires from the LED modules as shown in the image.

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/led_hub_step_23.png" width=700 class="zoom border center"></div>

12. Thread the battery strap through the mounting slots, and install the top plate using M3x6 screws (<a href="#cell9">Cell 9</a>).

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/top_plate_step_24.png" width=700 class="zoom border center"></div>

13. Install the side guards on the central standoffs and snap them onto the guard clips.

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/side_guard_step_25.png" width=700 class="zoom border center"></div>

14. Screw the video antenna onto the connector at the rear.

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/vtx_antenna_step_26.png" width=700 class="zoom border center"></div>

15. Install the propellers according to the reversed rotation direction ("props out"), as shown in the image.

    <div align="center"><img src="../assets/assembling_clever5_fpv/en/props_step_27.png" width=700 class="zoom border center"></div>

> **Caution** Check that no components remain unsecured. Before the first power-on, ensure that the propellers do not touch the canopy or wires.
